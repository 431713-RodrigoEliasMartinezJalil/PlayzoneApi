Acerca de PlayZone

¿Qué pasa cuando comprás un juego digital? Alguien tiene que saber qué juegos existen, quién los hizo, cuánto cuestan y en qué biblioteca terminan. PlayZone modela todo ese recorrido.

Un catálogo de videojuegos con sus géneros y estudios. Usuarios que se registran, compran con distintos medios de pago y arman su biblioteca. Una wishlist para los títulos que están esperando, promociones con fecha de inicio y fin, y reseñas donde cada jugador dice si recomienda o no lo que jugó.

Detrás hay una base de datos relacional, una Web API en C# con autenticación JWT y esta interfaz web que las conecta. Desde acá administrás productos y ventas, y el dashboard te muestra cómo viene el negocio.
